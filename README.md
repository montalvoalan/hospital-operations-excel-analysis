# Hospital Operations & Patient Care Analysis

## Project Overview

This project analyzes hospital patient records using Microsoft Excel to evaluate hospital utilization, patient encounters, costs, insurance coverage, procedures, and repeat visits.

The project is designed to demonstrate practical data analytics skills using Excel, including data preparation with Power Query, Excel formulas, PivotTables, data modeling, data visualization, and interactive dashboard development.

## Business Problem

Hospital leadership needs a clearer understanding of patient utilization, operational costs, insurance coverage, and procedure activity.

This analysis will investigate questions including:

- How has hospital utilization changed over time?
- Which encounter types account for the most patient visits?
- What is the average length of stay for different encounter types?
- Which patients have repeat hospital encounters?
- Which encounter types and procedures contribute the most to total costs?
- How much of hospital claim costs are covered by insurance?
- Which trends or areas may require additional operational attention?

## Dataset

The project uses the Hospital Patient Records dataset provided through the Maven Analytics Data Playground.

The dataset contains multiple related tables covering:

- Patients
- Encounters
- Procedures
- Insurance payers
- Healthcare organizations

The raw source files are stored in `data/raw/` and remain unchanged throughout the project.

## Project Workflow

1. Collect and preserve raw source data
2. Review the data dictionary and understand table relationships
3. Perform data quality checks
4. Import and transform data using Power Query
5. Build relationships using the Excel Data Model
6. Create calculated fields and Excel analyses
7. Build PivotTables and PivotCharts
8. Develop an interactive hospital operations dashboard
9. Identify key findings and business recommendations
10. Document the completed analysis on GitHub
